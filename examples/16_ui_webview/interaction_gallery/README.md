# 交互组件实验室

Workspace 页面集中演示 Tree 筛选与祖先路径、可选层级引导、节点动作、浮动标签输入框，以及由实际工作批次驱动的 TaskButton。支持失败、重试、取消、进度样式、三套主题、密度和减少动效。

All controls 页面演示三态勾选框、Switch、独立 Radio 与 RadioGroup、提交型 Slider、长按 Stepper、Tabs、分段控件、禁用选项、列表滚动、缓冲进度、语义 Badge、Card、原生 Editor、日期清空/今天、12 小时时钟和通知队列。

任务进度由 48 个真实计算批次更新；请求 ID 防止旧回调覆盖新的任务。实际文本编辑保留原生选区、剪贴板与输入法会话；文本撤销/重做历史尚未实现。


逐项检查全部 45 个入口及三主题、三密度、三字号，请运行 [component_workshop](../component_workshop/)。本示例继续专注工作流组合。
